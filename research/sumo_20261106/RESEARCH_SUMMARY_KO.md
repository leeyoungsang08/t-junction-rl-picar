# 연구 진행·재학습·결과 요약

## 1. 목표와 범위

SUMO의 단일 교차로에서 교통 상태를 입력받아 녹색 방향을 선택하는 강화학습 제어기를 만들고, 다른 수요·지도·센서 조건에 대한 효율과 장시간 대기를 평가했다. 중간 이후 실험은 세 방향 직접 선택형 DQN 계열과 별도 신호 보호기를 사용한다. 기존 저장소의 KEEP/SWITCH 모델이나 PiCar 통신 코드와 **행동 공간 및 입력 형식이 다르므로 모델 파일을 무작정 교체하면 안 된다.**

장차 PiCar 모형에 전이하는 것이 목표지만 실제 차량·트랙·카메라는 시험하지 않았다. 차로 길이와 차량 동역학, 신호 장치, 센서 오차를 실측해 SUMO를 보정하지 않았다.

## 2. 주요 진행 순서

| 시기 | 수행 내용 | 상태·해석 |
|---|---|---|
| 11월 3~4일 | 제공받은 프로젝트 재현, SUMO 평가, GUI 및 신호 시계열 확인, 보호기 수정과 재검토 | 코드·근거·한계를 각 보고서와 출력 묶음에 보존 |
| 11월 4일 | Colab의 다중 지도 학습: 5개 시드 × 600회, 300·600회 모델 비교, 시험 1,040회 | 600회 모델의 네 조건 평균 지연 지표 32.38초, 대기열 proxy 36.30초. 실측 데이터가 아닌 두 합성 T자 지도이며 300→600회 이득은 작았다 |
| 11월 5일 | 관측 오차를 변경한 3개 시드 × 600회 재학습, 새 지도 504회 비교 | 후보의 전체 평균은 기존 모델보다 불리했다. 첫 시험의 생성 네트워크 사본이 보존되지 않아 완전 재현성에 한계가 있다 |
| 11월 5일 | 같은 기존 가중치에서 미세조정 3개 시드 × 400회, 새 지도·수요 비교 및 추가 검증 | 이전 후보의 작은 평균 이득이 다른 지도에서 재현되지 않아 기존 모델 유지 |
| 11월 5일 | 추가 보상 페널티만 제거한 3개 시드 × 400회 및 576회 비교 | 일관된 개선 없음. 44번 시드의 선택 모델은 업데이트 0회인 기존 가중치였다 |
| 11월 5일 | 제한 관측을 보호기와 모델에 적용한 센서 시험·재학습 및 새 지도 시험 | 합성 누락·지연에 적응한 후보가 일부 조건에서 좋아졌지만 정상 감지에서 악화한 경우가 있었다 |
| 11월 5일 | balanceA 단일 지도, 일반/기존 정책 정규화 × 3시드 × 180회, 12개 보조 방식, 새 수요 1,080회 | 학습 후 36개 체크포인트와 보조 방식 12개 중 사전 정의된 조건별 기준을 통과한 모델은 없었다. 기존 가중치 유지 |
| 11월 5일 | 장시간 대기 감시기 두 설정, 별도 검증 144회와 새 수요 시험 360회 | 90초 감시는 시험의 관측 최장 연속 대기 167→98초, 평균 지연 33.23→33.28초. 개별 조건 악화가 남아 자동 채택하지 않았다 |

위 평균은 각 실험에 지정된 조건의 동일 가중 평균이다. 한 지도·시나리오를 공유하는 반복 실행을 독립적인 교차로 표본으로 취급하면 안 된다. 평가 시험 결과를 모델 선택에 다시 사용하면 해당 시험은 독립 평가가 아니다.

별도로 로컬 `formal_bench`에는 300회 계획 중 8회만 마친 중단된 실행이 남아 있다. 이는 완료된 300회 학습으로 집계하지 않았으며 원본 상태와 백엔드 검증 자료도 보존했다.

## 3. 주요 결과의 의미

`cohort_delay_s`는 완료 차량만의 평균 대기시간이 아니다. 요청 차량에 대한 정차·출발 지연과 시뮬레이션 끝까지 미진입한 차량의 경과 시간을 반영한다. 일부 과포화 조건은 900초 종료 시 상당수 차량이 도착하지 못하므로 완료율과 함께 해석한다. 장시간 대기의 최댓값은 개별 실험에서 관측된 값이고 보장된 상한이 아니다.

관측 오차를 신경망에만 적용하고 보호기는 SUMO 실제 상태를 사용하는 초기 평가에는 전이 가능성 한계가 있었다. 이후에는 감지된 대기열만 사용하는 보호기를 시험했으나, 차로 전체를 감지할 수 있다는 가정과 센서 오차·통신 지연은 실제 장비의 측정값이 아니다. 신호 상태는 신뢰할 수 있게 전달된다고 가정했다.

모델 학습을 더 오래 한다고 성능이 항상 좋아지지 않았다. 학습 시드와 검증 선택 모델, 초기 가중치, 학습 업데이트 수를 구분해야 한다. 예를 들어 180회 재학습을 끝냈어도 검증 선택 결과가 업데이트 전 가중치라면 이를 새로운 우수 모델이라고 부를 수 없다.

## 4. 참조 연구와 비교 한계

- [RESCO: Reinforcement Learning Benchmarks for Traffic Signal Control](https://openreview.net/pdf?id=LqRSh6V0vR): 관측 가정 및 교차로 형상 변화에 대한 벤치마크 관점.
- [Safe Policy Improvement with Baseline Bootstrapping](https://proceedings.mlr.press/v97/laroche19a.html): 기존 정책을 기준으로 한 보수적 개선의 연구. 본 프로젝트의 Q값 정규화·게이트는 이 논문 알고리즘의 구현이나 이론적 보장을 뜻하지 않는다.
- [GeneraLight](https://jhc.sjtu.edu.cn/~gjzheng/files/papers/cikm2022_generalight/cikm2022_generalight_paper.pdf): 교통신호 학습의 환경 일반화에 관한 연구.

본 프로젝트는 위 논문과 동일한 도로·교통 수요·센서·기준 제어기·실험 설계를 사용한 직접 재현 비교가 아니다. 논문 수치보다 좋거나 같다고 결론내리지 않는다.

## 5. 남은 작업

- 실제 PiCar/모형 교차로의 차체·속도·출발 지연·감지율·통신·신호 응답을 측정하고 SUMO를 보정한다.
- 보행자·다차로·하류 정체·고장 등 현재 범위 밖 조건과 더 많은 독립 수요·초기화에서 재검증한다.
- 평균 효율, 방향별 지연, 완료율과 장시간 대기 및 장애 시 동작을 함께 다루는 학습·선택 기준을 개선한다.
- 현재 노트북의 Drive 원본과 로컬 출력의 버전 차이를 확인하고, Drive에만 남은 원본 로그를 필요 시 별도로 보존한다.
