# T자 교차로 강화학습 결과 재검토

검토일 2026-11-04, 한국 시간

납품본의 수치는 Eclipse SUMO 1.28.0에서 학습하고 평가한 결과다. 납품본과 별도 재현본의 최종 평가 990회씩을 SUMO가 기록한 차량 단위 XML에서 다시 계산했다. 이 검토에서도 저장된 체크포인트로 SUMO를 450회 추가 실행했다. Direct Rainbow-lite의 요청당 지연 **18.17초**가 11개 시험 조건을 같은 비중으로 평균했을 때 가장 낮았다.

## 논문과 구현의 대응

| 원문 | 확인한 구현 | 구현 범위 |
|---|---|---|
| [Double DQN](https://arxiv.org/html/1509.06461) | `src/dqn_agent.py`에서 허용 행동 중 온라인 네트워크로 최대 Q 행동을 고르고 타깃 네트워크로 평가 | 신호 제약으로 행동 마스크를 추가했다. |
| [Dueling DQN](https://proceedings.mlr.press/v48/wangf16.html) | `src/dqn_network.py`의 상태 가치와 행동 이점 헤드, `V + A − mean(A)` 결합 | 논문의 분리 구조를 교통 상태 벡터용 MLP에 적용했다. |
| [Prioritized Experience Replay](https://arxiv.org/pdf/1511.05952) | `src/replay_buffer.py`의 `|TD 오차| + ε` 기반 비례 샘플링과 중요도 가중치 | 비례 방식의 기본 식을 사용한다. |
| [Rainbow](https://arxiv.org/pdf/1710.02298) | Double·Dueling·PER를 결합한 Rainbow-lite | 원 논문은 다단계 반환, 분포형 가치, NoisyNet도 결합한다. 이번 모델은 위 세 구성 요소를 사용한다. |
| [IntelliLight](https://faculty.ist.psu.edu/jessieli/Publications/2018-KDD-IntelliLight.pdf), [FRAP](https://arxiv.org/pdf/1905.04722), [PressLight](https://faculty.ist.psu.edu/jessieli/Publications/2019-KDD-presslight.pdf) | IntelliLight의 현재 현시 유지·다음 현시 전환과 FRAP·PressLight의 현시 직접 선택 개념을 비교 | 교통 상태·보상·신경망은 이 단일 교차로에 맞춰 구성했다. FRAP의 현시 쌍 경쟁 구조와 PressLight의 압력 보상은 구현에 들어가지 않는다. |
| [Varaiya의 Max-Pressure](https://www.sciencedirect.com/science/article/pii/S0968090X13001782) | `src/baselines.py`에서 정지한 진입 차량과 미삽입 대기 차량의 합을 비교하는 Max-pressure Proxy | 원 논문의 이동별 하류 큐·회전비·포화율을 이 기준선에 사용하지 않았다. |

납품본 문헌표의 Li 등 수요 변동 프리프린트는 2026-01-12 개정본에서 철회된 상태였다. 당시 문헌표에 철회 상태를 반영하지 못했다. 이번 정정 문헌표에서 해당 항목을 제외하고, IntelliLight 링크를 저자 측 PDF로 교체했다. 철회 자료는 최종 모델의 업데이트 규칙이나 SUMO 평가 계산에 사용되지 않았다. [arXiv 철회 기록](https://arxiv.org/abs/2511.00549v2)

## SUMO 실행과 집계 확인

- 납품본 및 재현본에서 각각 스모크 12회, 예비 학습 576회, 정식 학습 1,800회의 차량 XML 헤더, 학습 시드, 업데이트 로그를 대조했다. 각각의 PyTorch 최적화 업데이트 수는 372회, 67,608회, 318,006회였다. 스모크·예비는 SUMO 실행 파일에 TraCI로 연결했고, 정식 학습과 최종 평가는 Libsumo를 사용했다. 재현본에서 최적 체크포인트 34개의 가중치와 최저 검증 지연이 일치했다.
- 최종 평가는 **11조건 × 수요 시드 10개 × 제어기 9개 × 회차당 900초**다. 제어기는 정식 모델 6개와 기준선 3개다. 두 ZIP에서 SUMO 버전 및 수요 시드가 적힌 `tripinfo.xml`, 수요 XML, 초 단위 차량 집계를 읽었다. 110개 최종 수요 파일의 해시와 학습·검증 수요 분리, 지도 및 체크포인트 해시를 확인했다. 실행 시각은 납품본 11월 3일 22:54~22:56, 재현본 11월 4일 10:15~10:17이다.
- 지연은 진입 차량의 누적 정차와 삽입 대기, 미진입 차량의 예약부터 종료까지 대기를 합해 전체 요청 수로 나눈 값이다. 차량 XML에서 다시 계산한 지연과 각 CSV의 최대 차이는 8.53 × 10⁻¹⁴초였다. 두 ZIP에서 독립 계산한 990행은 모두 일치했다. 900초 이후에 이어지는 대기는 이 지표의 관측 범위 밖이다. [SUMO TripInfo 문서](https://eclipse.dev/sumo/docs/Simulation/Output/TripInfo.html)

| 제어 방식 | 조건 동일 가중 지연 (초/요청) | 차량 요청 수로 가중한 지연 (초/요청) | 조건 동일 가중 완료율 |
|---|---:|---:|---:|
| Direct Rainbow-lite | 18.17 | 26.43 | 92.6% |
| Max-pressure Proxy | 20.62 | 29.24 | 92.0% |
| Cycle Rainbow-lite | 24.56 | 36.66 | 91.2% |
| 규칙식 | 33.23 | 46.99 | 89.6% |
| 고정식 | 57.42 | 79.66 | 83.7% |

동일한 11개 조건에서 Direct의 평균 지연은 Max-pressure Proxy보다 11.9% 낮았다. High 조건의 짝 비교는 −0.75초, 95% 구간은 [−1.74, 0.24]초로 0을 포함한다. 방향 반전에서는 −4.04초 [−4.84, −3.23], 남쪽 과포화에서는 −4.15초 [−6.24, −2.07]였다. 각 조건에서 학습 시드 3개의 결과를 같은 수요 시드 안에서 평균한 후 수요 시드 10개를 짝지었다. 구간은 다중 비교를 보정하지 않았으며, 학습 초기화와 교차로 구조의 변동성은 포함하지 않는다.

## 새로 실행한 450회

기존 설정 재실행은 High·방향 반전·남쪽 과포화의 270회였다. 저장된 모델과 수요를 다시 사용한 결과, 기존 지표와의 최대 수치 차이는 3.64 × 10⁻¹¹이었다. 실행 시간과 저장 경로를 비교에서 제외했다. 추가 180회는 남쪽 과포화에서 옵션을 하나씩 바꾼 민감도 시험이다.

| 남쪽 과포화 설정 | 실행 수 | Direct 지연 / 완료율 | Proxy 지연 / 완료율 | 전체 제어기 텔레포트 / 충돌 |
|---|---:|---:|---:|---:|
| 기존 설정 재실행 | 90 | 89.97초 / 74.8% | 94.12초 / 73.3% | 25 / 0 |
| 대기 초과 텔레포트 해제 | 90 | 89.97초 / 74.8% | 95.77초 / 72.9% | 0 / 0 |
| 교차로 내부 충돌 검사 활성화 | 90 | 89.97초 / 74.8% | 94.12초 / 73.3% | 25 / 0 |

대기 초과 텔레포트 해제 후에도 남쪽 과포화에서 Direct가 Proxy보다 낮은 평균 지연을 보였다. 완료율은 약 75%여서 과포화 자체는 남았다. 기존 실행의 충돌 0건은 당시 검사 설정에서 기록된 값이다. 교차로 내부 차량 겹침을 확인하는 SUMO 옵션은 별도로 활성화해 남쪽 과포화 90회에서 확인했다. [SUMO 충돌 검사](https://sumo.dlr.de/docs/Simulation/Safety.html) · [SUMO 텔레포트](https://sumo.dlr.de/docs/Simulation/Why_Vehicles_are_teleporting.html)

결과의 적용 범위는 합성 수요가 들어오는 단일 T자 지도, 검증에서 고른 6개 정식 모델, 비교한 세 기준선이다. 고정식은 20초 녹색으로 설정했고 Max-pressure는 진입 큐 기반 proxy를 썼다. 정식 예산으로 다른 알고리즘 조합 18회, 다른 도로망, 실제 교통, Colab 호스트는 평가하지 않았다. 새 재실행과 두 민감도 시험은 같은 시험 수요를 재사용했으므로 독립 표본 수는 증가하지 않는다.

검토 근거 ZIP에는 정정 문헌표, 재계산 코드, 실행 옵션과 450회 집계 CSV, SUMO가 새로 작성한 차량·신호 원시 기록을 담았다.
