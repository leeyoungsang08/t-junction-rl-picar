# PiCar 연결 전 준비와 실측 양식

대상은 차량의 조향 제어가 아니라 **T자 교차로 신호 제어**다. 아래 값은 실제 장비가 없으므로 미측정이다. 이 문서의 센서 기능이나 수치를 이미 확보한 사실로 해석하지 않는다.

## 실제 장비가 준비되면 측정할 값

| 항목 | 기록할 값 | 현재 |
|---|---|---|
| 트랙 | W·E·S 유입로와 유출로 길이, 차로 폭, 정지선, 회전 경로 | 미측정 |
| 차량 | 차체 길이, 차간 거리, 평지 속도, 가감속, 정지 오차, 회전 시간 | 미측정 |
| 차량 출발 | 정지 상태에서 신호 확인 후 움직이기까지 지연의 분포 | 미측정 |
| 감지 | 카메라 또는 센서의 설치 위치, 감지 구역, 감지율·오탐률, 가림과 방향 구분 오류 | 미측정 |
| 통신 | 센서 수집 간격, 처리·전송 지연, 손실·중단 길이, 재연결 시 버퍼 전송 여부 | 미측정 |
| 신호 장치 | 허용 신호 현시, 최소 녹색, 황색·전적색, 장치가 실제로 적용됐다는 피드백 | 미측정 |
| 제어 연결 | 명령과 수신 확인 방식, 시간 동기화, 장애 감지·복구 및 독립적인 정지 수단 | 미정 |

동일 조건을 여러 차례 측정해 평균뿐 아니라 변동 범위와 최악값을 기록한다. 차량 대수, 조명, 가림, 속도, 통신 상태를 함께 기록해야 편향을 확인할 수 있다.

## 센서 상태 계약 초안

- 방향 순서는 W, E, S. 세 방향이 실제 트랙의 어느 접근로에 대응하는지 명시한다.
- 각 프레임에 수집 시각, 수신 시각, 방향별 유효 여부와 감지 차량 수·대기열 추정치를 기록한다. 값이 0인 것과 감지 실패는 구별한다.
- 신호 현시, 최소 녹색과 전환 상태는 센서 추정값이 아니라 신호 제어 장치에서 확인해야 한다. 장치 응답이 없으면 정상적으로 반영됐다고 가정하지 않는다.
- 현재 실험의 대기 연령은 감지된 대기열이 끊기지 않고 보인 시간의 대용치다. 실제 차량 개인의 대기시간과 다르며 보정 전에는 보장값이 아니다.
- 현재 SUMO 실험은 미진입 차량 수와 교차로 내부 차량 수를 0으로 대체했다. 실제 센서나 별도의 추정기로 확보하기 전까지 실제 값으로 바꿔 넣을 수 없다.

## 적용 전 단계

1. 트랙과 차량의 측정값을 이용해 SUMO 지도를 다시 만들고 속도·회전·출발 지연을 보정한다.
2. 실제 센서 기록을 재생해 감지 누락·지연 분포와 신호 입력을 검증한다. 모델에 제공하지 못하는 정보는 보호기에도 제공하지 않는다.
3. 모델이 신호를 추천만 하는 관찰 모드에서 제어기 상태·신호 추천·실제 결과를 동기화해 기록한다.
4. 독립적인 최소 녹색·상충 신호 금지·황색·전적색 전환 장치와 통신 장애 시 제어 계획을 확인한다. 현재 Python 실험은 장치 안전 인증이나 하드웨어 비상정지를 제공하지 않는다.
5. 차량 속도와 대수를 제한한 모형 교차로에서 감독하에 비교하고, 감지 실패와 명령 불일치가 발생하면 별도로 정의한 정지 절차를 실행한다.

이 준비는 실제 기기의 제원과 측정 결과를 대신하지 않는다. 학습된 신호 모델은 PiCar의 조향이나 속도 명령을 직접 출력하지 않는다.

## 신호 추천 시제품의 범위

`SUMO_PiCar_신호추천_시제품.py`는 기존 SUMO 모델과 프로젝트의 `src` 모듈을 불러오는 관찰 모드 시제품이다. 신뢰할 수 있는 신호 장치 상태를 초당 한 번, 방향별 감지 수를 5초마다 외부 호출자가 전달한다고 가정한다. 실제 카메라·통신·신호 장치와 연결하지 않으며 방향 추천만 반환한다. 최초 센서 프레임이 없으면 추천하지 않고, 오래되거나 잘못된 프레임, 불연속 신호 상태 및 모델과 다른 신호 설정은 거부한다. 연속 3회 프레임이 빠지면 고정시간 대체 방향을 추천하며, 이때 오래된 대기열 정보로 추천을 덮어쓰지 않는다. 기기에 이 추천을 적용하는 독립 신호 제어기와 하드웨어 정지 절차가 별도로 필요하다.

단위 시험은 위 입력 검증과 누락 분기를 확인한 것이며 실제 장비·카메라·통신의 성능이나 안전성을 검증하지 않는다. 실험의 1초·5초 주기, 10초 프레임 유효 시간, 세 번 누락 및 고정시간 계획은 가정이며 실제 장치에서 측정·재검토해야 한다. 시제품은 프로젝트 소스와 체크포인트가 필요하므로 단독 `.py` 파일만으로 실행할 수 없다.
