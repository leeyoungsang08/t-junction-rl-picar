# 상태, 행동, 보상

방향 순서는 W, E, S입니다. 신호 제어기의 상태와 방향별 교통 집계를 결합해 25개 특성을 입력합니다.

| 인덱스 | 특성 | 계산 |
|---|---|---|
| 0–2 | 진입 차량 수 | 진입 도로에 삽입된 전체 차량 수 |
| 3–5 | 평균 연속 정지시간 | 진입 차량의 TraCI waitingTime 평균 |
| 6 | 내부 차량 수 | 내부 링크에 있는 차량 수 |
| 7–9 | 현재 현시 | W/E/S one-hot |
| 10–11 | 녹색 경과시간, 전환 여부 | 경과 초, 황색·전적색 여부 |
| 12–14 | 정지 큐 | 진입 차량 중 속도 0.1 m/s 미만 차량 수 |
| 15–17 | 진입 대기 | 도착 요청 시간이 지났으나 SUMO가 삽입하지 못한 차량 수 |
| 18–20 | 장기 대기 | 현재 진입 차량의 누적 정지시간과 미삽입 차량의 대기시간 중 최댓값 |
| 21–23 | 최근 요청 | 지난 30초에 발생한 도착 요청 수 |
| 24 | 전환 잔여시간 | 녹색 복귀 전까지 남은 황색·전적색 초 |

교통 특성은 `x/(scale+x)`로 변환합니다. 방향별 집계는 개별 차량의 위치·속도를 모두 보존하지 않습니다.
최근 요청과 진입 대기는 현재 시점까지 발생한 요청만 집계합니다. 실제 센서로 옮길 때는 검지 구역 밖의 대기·도착을 측정하거나 추정해야 합니다.

행동 0은 유지, 1은 W→E→S 순환에서 다음 방향으로 전환입니다.
안전 제어기는 최소·최대 녹색 10–45초와 황색 3초·전적색 1초를 강제합니다.
5초 결정 격자 때문에 두 번째 현시부터 자발적 전환이 가능한 첫 녹색 길이는 보통 11초입니다.
`action`은 해당 결정 시점의 요청이며, `forced_switches`와 초 단위 `tls_state`가 실제 전환을 나타냅니다.
별도 우회전 허용이나 임의 방향 선택은 이 안전 현시 모델의 범위 밖입니다.

복합 보상은 매초 `-(1.5*w + 0.2*i + 0.5*s + 0.1*switch)`를 계산해 합산합니다.

- `w`는 도로 위 정차 차량과 삽입 대기 차량의 합을 30으로 나눈 값입니다. 대기 차량 한 대가 1초 더 기다릴 때 1 vehicle-second를 반영합니다.
- `i`는 내부 정차 차량과 내부 점유 2대 초과분을 합해 5로 나눈 값입니다.
- `s`는 각 방향의 최장 대기에서 35초를 넘긴 부분의 합을 90으로 나눈 값입니다.
- `switch`는 해당 초에 시작된 전환 수입니다. `simple` 모드에서는 정지 큐만 사용합니다.

계속 운영하는 교차로를 시간 제한으로 자릅니다. 학습은 해당 전이의 마지막 관측에서 유효 행동을 적용해 bootstrap합니다.
