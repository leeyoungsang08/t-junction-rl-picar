# 실험 설계

`smoke`는 3×180초, `quick`은 24×600초, `revision`은 80×600초, `full`은 300×900초입니다.
개선판 검증에는 `revision`을 사용했습니다. seed 42·43·44에서 신경망 초기화, 탐험, replay 샘플링을 독립적으로 실행했습니다. 학습 수요 파일은 동일하게 설정해 신경망 학습의 변동을 비교합니다.

학습은 low, medium, high, W/E/S 편중, rush_hour, rotating을 순환합니다. 검증은 별도 교통 seed에서 medium, W/E/S 편중, rotating을 평가합니다. 시드별 검증 평균 cohort 지연이 가장 낮은 모델을 저장합니다.

기존 `unseen`은 이전 검토에서 이미 본 남쪽 혼잡 조건입니다. 새 `heldout_reversal`은 별도로 둔 S→E→W 수요 전환 조건입니다. 두 조건은 모두 학습·검증에서 제외합니다.
최종 비교는 새 교통 seed 3120–3123으로 진행하며, 모델을 고정한 뒤 평가합니다.
